# RESEARCH REQUEST — 기수·비례 양화 gold source 조사

> **개정 2 (2026-08-23, 같은 날)**: 최초 요청은 기수 양화만 다뤘다. 그 후
> 비례 판별 술어를 정정하고 재census한 결과 **비례 양화(`most of …`,
> `Most N …`) 재료도 PMB에 0건**임이 확정돼 같은 조사에 포함한다.
> 이미 공유된 판을 읽었다면 **§1의 두 번째 범주와 R3'만 추가로 보라.**

- 수신자: **조사용 agent** (다른 workspace, zero context 전제 — 이 문서가
  맥락 전부. 설계용 agent 아님)
- 발신: ConceptGate 운영 세션, 2026-08-23
- 후속: 회신을 운영 세션이 검증 후, 적격성은 별도 기계 실측.
  **조사에게 적격성 판정을 청하지 않는다** — 접근·라이선스·형식·규모의
  사실 확인만.

## 1. 배경 (필요한 최소한)

문장 단위 의미 컴파일 실험의 수용 오라클로, **문장 하나와 그 형식 의미
표상이 1:1로 짝지어진 사람 저작 gold**를 쓴다. 측정 대상은 양화 scope
구조이고, 선언된 하위 범주에 **`cardinal_quantifier`**(기수 양화)가
포함돼 있다.

기존 두 source로는 이 범주를 채울 수 없다는 것이 실측으로 확정됐다:

- **PMB 5.1.0 gold (영어)**: 전수 스캔 후 기수 후보를 정밀 판별한 결과
  실질 재료가 **4건**뿐이고, 그 4건이 전부 `Each person paid <금액>` 류
  동일 구문이다. 게다가 그 수량은 **목적어의 액수**이고 문장의 overt
  양화사는 `Each`(보편)다 — 즉 기수 **양화**가 아니다. 진짜 기수 표현
  (`at most 20`, `three men`, `two peninsulas`)이 있는 문장은 전부 대명사
  또는 고유명을 포함해 별도 판정으로 제외된다.
- **FOLIO v0.0**: 다중 양화 전담으로 이미 사용 중이고, 기수 양화는
  다루지 않는다(연산자 집합에 기수 없음).

**비례 양화도 같은 상태다 (개정 2에서 추가)**: 판별 술어를 정정한 뒤
(bare `most` 정규식 → `most of` / `Most + 명사`만 인정, 최상급 `the most`·
`X's most`·상한 `at most` 배제) PMB 전수 재census 결과 비례 양화 문장은
**적격 0건**이다. 유일한 후보 "Most Americans have a sense of humor."는
`Americans`가 고유명 판정에 걸려 별도 규칙으로 탈락한다. 최초 census에서
비례로 잡혔던 "The most beautiful flowers…"는 최상급 오분류였다.

찾는 것: **기수 양화 또는 비례 양화 문장 + 사람 저작 형식 의미 표상**을
문장 단위로 공급할 수 있는 공개 자원 (두 범주를 한 자원이 다 채워도 좋고,
각각 다른 자원이어도 좋다).

**범주 1 — 기수 양화의 범위**: 명사구의 수량을 한정하는 양화 —
정확수(`exactly three dogs`), 하한(`at least two`), 상한(`at most five`),
단순 기수(`three dogs barked`). **제외**: 목적어의 액수·나이·연도 같은
단순 수치 언급, 관용구(`no one`, `many a`), 모호 수량(`several`, `many`)
만 있는 문장.

**범주 2 — 비례 양화의 범위**: 집합의 비율을 한정하는 양화 —
`most of the students`, `Most cats sleep`, `a majority of X`,
`more than half of X`. **제외**: 최상급(`the most beautiful`,
`her most famous`), 상한 기수(`at most N`), 부사 `mostly`.

**독립성 조건 (기존 판정 D-E2E-v1-22 §13 verbatim — 하나라도 어기면
후보가 아니다):**

```yaml
second_source:
  different_corpus_authority: true      # 기존 두 source와 다른 기관/저작 주체
  independently_authored_gold: true     # 사람이 저작·검수한 gold
  not_derived_from_PMB: true            # PMB 재수출·변환판 금지
  not_project_generated: true           # 우리가 생성한 쌍 금지
  separate_source_locator: true
  separate_adapter_profile_if_formalism_differs: true
```

이 프로젝트가 데인 실패 3건을 피하라:
1. **라이선스를 정책으로 추정 금지** — 배포처 명시 문구를 verbatim 인용.
   (사고 이력: 학회 정책 추정 "CC BY 4.0" → 실제 PDF는 CC-BY-NC)
2. **원문 철자·URL을 문자 그대로 시도** — 이상해 보여도 교정 전에 그대로.
   (사고 이력: 논문의 `/dwnload`를 `/download`로 "교정"했다가 404 → 부재 오판)
3. **"확인 못함"(BLOCKED)과 "없음"을 구분**하라. 접근이 막힌 것은 BLOCKED다.

## 2. 조사 질문 (사실 확인 6건)

### R1 — 후보 목록 (3~6개)
기수 양화 문장 + 형식 의미 표상 쌍을 제공하는 공개 자원 후보. 우리가 이미
아는 계열(각각 왜 되는지/안 되는지 **사실만**):
- **PMB / Groningen 계열** — 위 실측대로 부적합(파생판도 `not_derived_from_PMB`로 탈락)
- **FOLIO** — 기수 없음
- **GQ/generalized quantifier 데이터셋류**, **FraCaS test suite**(§4 주의),
  **CCGbank 파생 논리식**, **GeoQuery / ATIS / Overnight**(의미 파싱 gold,
  기수 포함 가능성), **SICK / SNLI**(형식 표상 없으면 탈락),
  **WebNLG·AMR 계열**(AMR에 `quant` 역할이 있음 — 형식 표상으로 볼 수
  있는지가 R4의 판단 재료), **QuantML / ISO 24617-12** 준거 코퍼스
후보마다: 저작 주체 · 형식(표상 문법) · 규모 · 접근 경로.

### R2 — 각 후보의 라이선스
명시 문구 **verbatim**. LICENSE 파일 / 배포 페이지 / 논문 표기가 서로
다르면 **셋 다** 따로 인용. 재배포·상업 조건 문구가 특히 중요하다
(우리는 원문을 저장소에 담지 않고 해시·locator만 커밋하지만, 로컬 캐시
사용 조건이 걸린다).

### R3 — 기수 양화 실재 신호
각 후보에서 **§1 범주 1의 기수 양화 정의를 만족하는 문장**의 실물 예
2~3건(짧게, 가능하면 표상 조각 포함). 규모 신호(정확 수 불요, 출처 명시).
`several`·`many`만 있는 예는 이 범주가 아니므로 제외하고 보고하라.

### R3' — 비례 양화 실재 신호 (개정 2에서 추가)
같은 형식으로 **§1 범주 2**(비례)의 실물 예 2~3건. 최상급이 섞이지 않게
하라 — 우리 쪽에서 그 오분류로 잘못된 fixture가 네 번의 동결을 통과했다.
비례를 표상에서 어떻게 인코딩하는지(전용 연산자? 비율 상수? 일반화 양화자
2-람다?)를 R4에 함께 적어라.

### R4 — 형식 문법의 정본
각 후보의 표상 문법을 정의한 문서(논문/매뉴얼) 위치. **기수를 표상에서
어떻게 인코딩하는지**(전용 연산자? 수치 상수? 술어 인자?)를 실물 조각으로.
**표상이 함의 라벨(entailment label)뿐이면 "형식 표상 없음"으로 명기하라**
— 함의 라벨은 우리 오라클이 될 수 없다(FraCaS가 이 경우일 가능성).

### R5 — 수작업 저작 여부
gold가 사람 저작인지, 문법에서 자동 생성됐는지. 자동 생성이라도
**제3자가 저작·공개한 완성 artifact**면 후보다(우리가 생성하면 탈락).

### R6 — 문장 단위 1:1 여부
문장 원문과 표상이 **문장 단위 1:1**인가, 아니면 문서·대화 단위인가.
혼재하면 구분 방법도.

## 3. 우리가 자체 실측할 것 (조사 범위 아님 — 참고용)

수령 후 운영 세션이 기계 실측하는 적격성: 문장 단위 1:1 / 외부 저작 오라클
/ 해당 양화 실재 / 동결된 subject 방언으로 표현 가능 / 적격 항목
**기수 ≥3건, 비례 ≥1건** / 표면 필터(대명사·고유명 배제) 통과 / 투영 신호
보존 게이트 통과 / 측정 가능성 게이트 통과. R4의 문법
정본이 있어야 adapter를 만들 수 있으므로 **R4가 R3보다 중요하다**.

## 4. 보고 형식

R항목별로: **사실 / 근거(URL·파일 경로·verbatim 인용) / 확신도 / BLOCKED
여부**. 시도했으나 실패한 경로도 기록하라(무엇을 어떻게 시도했는지 —
부재 판정의 근거가 된다). 후보 순위는 매겨도 좋으나 근거를 사실로 한정하라.
