# DESIGN REQUEST — 구속 조건은 R1이 아니라 R2(독립 검증 가능성)다 (Q36)

- 발신: 2026-08-24, 운영 세션 · 수신: 외부 설계 담당
- 판정자 전제: **저장소 접근 없음.** 자기완결적이다 — 고리 구조·요건·후보·수치를
  전부 본문에 싣는다.
- 성격: **D-35 말미가 명한 다음 단계의 수준을 올리는 질문.** 판정은
  "`Name`/`ANA` 주석의 의미와 정확성을 독립 검증할 수 있는지"를 다음으로 했다.
  그 질문을 그리다가 **`Name`/`ANA`만의 문제가 아니라는 것**이 드러났다.
- 여전히 경계를 제안하지 않는다 — `operational_patch: forbidden` ·
  `immediate_projection: forbidden` 준수. 코호트 dispatch 누계 **0건**.

## 1. 고리를 그렸더니 병목이 바뀌었다

순환을 그래프로 그려 단계별로 파고들었다(추상 → drill-down → 렌더 → 직접 읽기 →
정교화). 고리는 이렇게 닫힌다:

```text
       순수 measurand (Y_scope = f(scope 능력))
              │ 필요하다
              ▼
       scope 와 encoding 의 분리
              │ 필요하다
              ▼
       referential ∃ 경계
              │ 정한다
              ▼
       무엇이 정답인가 (채점 계약)
              │ 정의한다
              └──────────────► (되돌아) 순수 measurand
```

**우리가 시도한 네 가지가 전부 이 고리를 끊지 못한다:**

| 시도 | 왜 못 끊나 | 근거 |
|---|---|---|
| synset 으로 경계 | 하나의 label 이 여러 부류에 대응(식별 함수 아님) | `person.n.01`이 양화·지시·보통명사 세 부류 |
| 표면 목록으로 경계 | **목록 선택이 이미 부분적 경계 결정**이다 | 4회 실패 · 유형화 비율이 목록 구성에 따라 **2%~51%** |
| FOLIO 규약 채택 | corpus 규약을 semantic authority로 승격 | D-34 §9 기각 |
| `Name`/`ANA` 를 권위로 | 증거지 충분조건 아님 | D-35 |

**끊는 간선은 하나다**: apparatus 밖의 권위. 그 간선의 자격 요건을 판정문과
우리 실측에서 도출하면 넷이다.

| 요건 | 내용 | 출처 |
|---|---|---|
| **R1** | apparatus 밖에서 **의미 부류를 기록**한다 | D-34 §5("measurement apparatus가 semantic boundary를 이미 가지고 있지 않다") |
| **R2** | 그 기록의 **정확성을 독립 검증**할 수 있다 | D-35 §9(검증되지 않은 주석을 권위로 쓰는 것은 순환) |
| **R3** | 미포함분을 선언한다(부재 ≠ 음성) | D-35 §6·§7 |
| **R4** | 두 source 에 같은 기준 | 미해소 — PMB·FOLIO |

후보 유형을 요건에 붙이니 이렇게 갈린다(**이 연결은 우리 판단이다**):

```text
R1 ← 사람 판정 · 다른 주석 corpus · 언어학 이론 · 판정 채널   (넷 다)
R2 ← 사람 판정 · 판정 채널                                  (둘만)
R4 ← 다른 주석 corpus · 언어학 이론                          (둘만)
```

**다른 주석 corpus는 R1·R4를 채우고 R2에서 막힌다** — "또 다른 검증되지 않은
주석"이므로 방금 겪은 순환을 그대로 물려받는다. **판정 채널은 R2에서 자기 검증
문제**가 생긴다(자신의 판정을 자신이 검증할 수 없다).

우리는 이 작업을 "apparatus 밖 source 찾기"(R1)로 이해하고 있었다. **구속
조건은 R2다.**

## 2. R2의 부분 기제를 하나 찾았다 — **corpus 내부 구조 일관성**

주석의 *의미*를 우리가 판정할 수는 없다. 그러나 **그 주석이 한 가지 것으로
일관되게 쓰였는지**는 corpus 구조로 확인된다. `ANA`에 대해 실측했다.

```text
ANA      노드 간선 위치(synset 다음)   1,036 / 1,036   (100%)
NEGATION 행 첫 토큰 위치(box 연산자)      546 /   546   (100%)
                                    → 두 위치가 완전히 분리된다
```

`ANA`는 전건이 노드 간선이고, 확실한 box 연산자(`NEGATION`)는 전건이 행 첫
토큰이다. 즉 **`ANA`는 일관되게 한 종류로 쓰였다.**

같은 방식으로 D-35 §6의 비대칭도 확인했다 — 같은 `(synset, 표면)` 쌍이 주석
유무 양쪽에 나타난다(`male.n.02 'he'`: 주석 82 · 무주석 990). **주석 부재는
표현의 성질이 아니라 범위다.**

**이 기제의 한계**: 일관성은 정확성이 아니다. `ANA`가 항상 같은 자리에 쓰였다는
것은 **의미가 무엇인지 말해 주지 않는다.** R2의 일부만 채운다.

## 3. R2의 구체적 공백 — 우리는 **전사(轉寫)를 갖고 원천을 갖지 않았다**

우리 코드에 이 주석이 있다(2026-08-23 적대검증 라운드가 남긴 것):

```text
# 적대검증(2026-08-23): ANA는 sbn_spec.py 기준 DRS_OPERATORS(비교/역할 계급)
# 이지 box 연산자가 아니다 — 초기 census의 오분류 잔재를 스펙 권위로 정렬.
```

즉 `ANA`의 분류는 **주석 규약 사양(`sbn_spec.py`)을 권위로** 삼아 정해졌다.
그리고 우리 설계 문서 §2는 "`sbn_spec.py`에서 확인한 실행 가능 사양"이라며
패턴들을 옮겨 적었다.

**그런데 `sbn_spec.py`가 우리 저장소에 없다.** 검색해서 확인했다. 우리가 가진
것은 그 사양의 **전사**이고 원천이 아니다. 따라서 `ANA`·`Name`이 규약상 무엇을
뜻하는지 **우리는 재검증할 수 없다** — 전사가 맞는지 확인할 대조본이 없다.

이것이 R2의 공백을 구체적으로 만든다: 우리는 주석의 의미를 규약 사양에
의존해서 알고 있고, **그 사양을 손에 갖고 있지 않다.**

## 4. 우리가 모르는 것 — 주석자 간 일치도(IAA)

주석 정확성의 표준 검증 수단은 **주석자 간 일치도**다. PMB가 그것을 공표하는지
**우리는 모른다.** 우리 저장소·캐시에 PMB 문서가 없고(읽지 않은 PDF 하나가
있다), 우리 기록에 IAA 언급이 0건이다.

**이것을 "없다"고 쓰지 않는다** — 우리가 안 찾은 것과 없는 것은 다르다. 이
문서가 그 구분을 지키는 이유는 이 세션에서 부재를 단정하다 다섯 번 틀렸기
때문이다.

## 5. 묻는 것

- **(a) R2가 실제로 구속 조건인가?** 우리는 요건 넷을 판정문에서 도출했으나
  그것은 판정받은 목록이 아니다. R1~R4가 맞는 분해인가, 우리가 요건을
  발명했는가?
- **(b) §2의 내부 구조 일관성이 R2의 부분 충족으로 인정되는가?** 일관성이
  정확성의 필요조건이라면 부분 충족이고, 무관하다면 R2는 여전히 비어 있다.
- **(c) 자기 검증 문제를 피하는 source가 있는가?** 사람 판정과 판정 채널이
  R2에 붙는 유일한 후보인데 둘 다 "자신의 판정을 누가 검증하는가"를 만든다.
  이것이 **원리적 한계인가 아니면 절차로 해소되는가**(예: 둘의 독립 교차)?
- **(d) `sbn_spec.py`를 확보하는 것이 R2의 선행 조건인가?** 그렇다면 그것은
  재료 취득 문제이고 우리가 할 수 있다. 아니라면 전사로 충분한 이유가 무엇인가?
- **(e) R2를 아무 source도 채우지 못하면 무엇이 따라오는가?** D-34의 (c)
  ("경계 정의가 원리적으로 불가")로 가는가, 그리고 그때 동결된 in-N PMB
  재료는 어떻게 되는가?

**운영 세션은 어느 것도 권고하지 않는다.** (a)가 축이다 — 우리가 요건을
발명했다면 이 문서 전체가 잘못된 문제를 푼다.

## 6. 한계

- **요건 R1~R4와 후보 유형 4개는 우리가 열거한 것**이다. 다섯 번째 후보나
  다섯 번째 요건이 있을 수 있고 우리 그림은 그것을 보여주지 못한다.
- **어느 후보가 어느 요건을 채우는가는 우리 판단**이다. 특히 "다른 주석
  corpus가 R2를 못 채운다"가 틀리면 §1의 결론이 틀린다.
- §2의 위치 분포는 **`ANA`와 `NEGATION` 두 토큰**만 본 것이다. role 어휘는
  200종이고 우리가 검토한 것은 `Name`·`ANA` 둘이다(`EQU` 12,501건 미검토).
- §3에서 우리는 처음 "우리 기록이 `ANA`를 오분류했다"고 쓰려 했다. **저장소를
  확인하니 저장소는 맞았고** 오류는 작업 노트에만 있었다. 보고 전에 확인했다.
